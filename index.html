Touch Kyushu 실전 사용법

10/9~10/10 · 어디서 무엇을 터치할지
제일 중요한 원칙
구매할 때 사용한 결제수단을 여행 중에도 그대로 사용한다. Apple Pay로 샀다면 같은 iPhone의 같은 카드를 사용하고, 실물카드로 샀다면 그 실물카드를 사용한다. JR에서는 탈 때와 내릴 때 모두 터치결제 전용 리더에 터치한다. 시설에서는 입구의 전용 단말기에 터치한다. 교통계 IC카드나 다른 카드를 잘못 대면 일반 운임으로 처리될 수 있으니 Pass Case용 결제수단을 확실히 구분한다.
사용기간2일권은 지정한 10/9과 다음 날 10/10에 유효. 마지막 날 25:00까지 이용 가능.
JR 범위가고시마 본선 모지코(門司港)~구로사키(黒崎). 보통·쾌속열차의 보통차 자유석만 이용.

JR 개찰구에서

  • 역에 들어갈 때 タッチ決済 / Contactless 표시가 있는 자동개찰기·폴형 리더·전용기기를 찾는다.
  • Apple Pay로 구매했다면 구매한 카드를 iPhone에서 선택해 리더에 터치한다.
  • 목적지 역에서 나갈 때도 같은 iPhone·같은 카드로 다시 터치한다.
  • JR에서는 Pass Case 화면 제시보다 구매에 사용한 결제수단의 터치가 핵심이다.
  • 특급 지정석이나 범위 밖 구간은 패스 대상이 아니다. 이번 일정에서는 보통·쾌속만 고르면 된다.

시설에서

  • Space LABO, 사라쿠라산 케이블카·슬로프카, 모지코 레트로 전망실 등에서는 입구의 Touch Kyushu 전용 단말기에 같은 결제수단을 터치한다.
  • Space LABO는 상설전만 패스 대상. 플라네타륨·특별전은 포함되지 않는다.
  • 기간 안에는 대상 JR 승차와 대상 시설 입장 횟수 제한이 없다.
  • THE OUTLETS 같은 제휴 특전은 단말기 터치가 아니라 Pass Case 화면 제시 방식이므로 구분한다.
10/9 금요일 · 고쿠라 → Space LABO → 몽벨 → 사라쿠라산PASS DAY 1
1
고쿠라역 → 스페이스월드역

고쿠라역에서 JR 가고시마 본선(鹿児島本線) 서쪽 방향 열차를 탄다. 전광판에서 스페이스월드 정차 여부를 확인하고 보통 또는 쾌속을 선택. 들어갈 때와 스페이스월드역에서 나갈 때 모두 같은 iPhone/카드를 Touch 결제 리더에 터치.

2
Space LABO 상설전

스페이스월드역에서 도보 이동. 입구 패스 전용 단말기에 구매 때 사용한 iPhone/카드를 터치. 상설전은 패스 대상이고 플라네타륨·특별전은 제외.

3
THE OUTLETS KITAKYUSHU · 몽벨

Space LABO에서 아울렛으로 이동. 몽벨 쇼핑 전이나 후에 안내센터에서 Pass Case 화면을 보여주면 Touch Kyushu 제휴 쇼핑 특전을 받을 수 있다. 몽벨에서의 사용 가능 여부는 현장 확인.

4
스페이스월드역 → 야하타역

가고시마 본선 서쪽 방향을 탄다. 야하타(八幡)는 스페이스월드 다음 역. 승차·하차 때 각각 같은 결제수단으로 터치.

5
야하타역 → 사라쿠라산 산록역

10/9은 평일이라 무료셔틀의 야하타역 첫 출발이 17:05. 일몰 여유를 위해 올라갈 때는 계획대로 택시가 안정적. 셔틀을 쓴다면 야하타역을 나와 로터리 왼쪽, 니시테츠 버스정류장 옆의 사라쿠라산 케이블카 표지를 찾는다.

6
산록역 → 케이블카 → 슬로프카 → 정상

산록역 전용 단말기에 같은 iPhone/카드를 터치. 산록역 → 케이블카 → 산상역 → 슬로프카 → 전망대역 순서. 케이블카 약 6분, 슬로프카 약 3분이며 둘 다 패스 대상.

7
야경 후 → 야하타역 → 고쿠라역

내려온 뒤 무료셔틀 시간이 맞으면 산록역의 후모토 식당 옆 정류장에서 야하타역으로 이동. 야하타역에서는 가고시마 본선의 고쿠라·모지코 방향 보통/쾌속으로 복귀하며 입·출장 모두 터치.

10/10 토요일 · 고쿠라 → 모지코 → 가라토 → 모지코 → 고쿠라PASS DAY 2
1
고쿠라역 → 모지코역

고쿠라역에서 가고시마 본선의 모지코(門司港) 방향 열차를 탄다. 모지코는 종점. 고쿠라에서 들어갈 때와 모지코에서 나갈 때 같은 iPhone/카드를 터치.

2
모지코 → 가라토 연락선

페리는 Touch Kyushu 대상이 아니다. 패스를 터치하지 않고 별도 승선. 가라토시장과 아카마신궁도 패스 대상 시설이 아니다.

3
모지코 복귀 후 패스 집중 사용

모지코 레트로 전망실에서는 입구 전용 단말기에 터치. 시간이 남으면 간몬해협뮤지엄, 구 오사카상선, 구 모지미쓰이클럽도 패스 대상이라 동선에 맞춰 추가 가능.

4
모지코역 → 고쿠라역

가고시마 본선에서 고쿠라·구로사키·오리오·하카타 방면 열차 중 고쿠라에 정차하는 보통/쾌속 이용. 모지코 승차와 고쿠라 하차 시 모두 같은 결제수단으로 터치.

이번 여행에서 PASS가 안 되는 것

  • 10/8 고쿠라성: 패스 자체는 대상이지만 시작일이 10/9라 이날은 사용 불가.
  • 기타큐슈공항↔고쿠라 공항버스
  • 야하타역↔산록역 택시
  • 모지코↔가라토 연락선
  • 가라토시장·아카마신궁·식당·카페·일반 쇼핑

문제 생겼을 때

  • 개찰구가 반응하지 않으면 여러 카드를 연속으로 대지 말고 구매에 사용한 카드가 맞는지 먼저 확인.
  • Pass Case에서 10/9 시작 2일권이 정상 표시되는지 출발 전날 확인.
  • 시설이나 열차를 한 번이라도 이용한 뒤에는 환불 제한이 생길 수 있음.
  • 10/9~10/10은 iPhone 배터리와 보조배터리를 특히 신경 쓴다.

몽벨 쇼핑 시 확인

일본에서 몽벨 Tax-Free

  • 이번 여행은 2026년 11월 제도 개편 전이라 현재 방식대로 매장에서 즉시 소비세 면제 처리.
  • 일반물품은 같은 면세점에서 하루 세전 합계 ¥5,000 이상이 기준.
  • 여권을 반드시 지참하고, 구매품은 일본 밖으로 반출해야 함.
  • 일본에서 Tax-Free 받았다고 한국 입국 때 자동 면세되는 것은 아님.

한국 귀국 시 현재 면세범위

  • 일반물품: 1인 합계 미화 US$800 이하.
  • 주류: 일반물품 한도와 별도로 합산 2L 이하 + 총 US$400 이하.
  • 담배: 궐련 200개비.
  • 향수: 100mL.
  • 초과 시 신고. 자진신고하면 관세 30% 감면(20만원 한도).
첨부 화면과 차이: 첨부 이미지에는 일반물품 20만원, 주류 3병(760mL 환산), 향수 2oz 등으로 표시돼 있지만 현재 관세청 공식 안내는 위 기준과 다르다. 그래서 웹페이지에는 최신 공식 기준을 반영했다. 몽벨을 크게 살 경우 친구 개인 구매액이 US$800 상당을 넘는지만 귀국 전에 계산하면 된다.
