# 기타큐슈 3박 4일 최종 GitHub Pages

기존 GitHub Pages 저장소의 최상단에 이 폴더의 파일을 전부 업로드/교체하면 됩니다.

파일: `index.html`, `favicon.svg`, `site.webmanifest`, `sw.js`, `.nojekyll`, `README.md`

## 이번 버전
- 친구용 Visit Japan Web / Touch Kyushu / eSIM 체크
- 준비물 체크박스
- 국내 Kakao Map 목적지 링크
- 08:20 국제선 기준 청주공항 06:20~06:30 도착 목표
- 각 일정 삭제/전체 복원
- 삭제에 따라 일별 예상지출 자동 재계산
- 경로별 예상비용과 날짜별 예상지출
- 놓치기 쉬운 주의사항
- 모든 계획은 유동적으로 변경/삭제 가능하다는 원칙

체크박스와 삭제 상태는 각 사람의 브라우저 localStorage에만 저장되므로 서로 영향을 주지 않습니다.
